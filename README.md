# 📊 Data Jobs Analysis Dashboard

An interactive data visualization project designed to explore the 2024–2025 landscape of data-related professions. This dashboard provides deep insights into job availability, salary distributions, and market trends across various roles like Data Engineering, Data Science, and Analytics.

## 🚀 Key Features
This dashboard is built to be fully dynamic, allowing users to drill down into specific market segments:

* **Executive KPIs:** Real-time tracking of **Total Job Count (479K)**, **Median Yearly Salary ($113K)**, and **Avg. Job Rating**.
* **Dynamic Slicers:** A "Job Title" slicer that filters the entire report, updating salary and volume metrics instantly.
* **Trend Analysis:** A "Jobs Over Time" line chart showing the hiring pulse from Jan 2024 to Nov 2024.
* **Salary Benchmarking:** A scatter plot comparing **Hourly vs. Median Salary** to identify high-paying roles (e.g., Software Engineers at $155K).
* **Detailed Job Stats:** A comprehensive table featuring sparklines for trend visualization and granular salary breakdowns.
